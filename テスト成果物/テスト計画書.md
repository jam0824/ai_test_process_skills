# テスト計画書

## 1. テスト目的

老後資金シミュレーターが、仕様書で定義された簡易モデルに従って手取り、ライフサイクル、投資、ランダムイベント、投資補填、給与変更、結果表示を正しく処理できることを確認する。特に、利用者の財務判断の目安となる計算結果が仕様どおりであること、入力した財務情報が外部送信されないこと、主要ブラウザで基本操作が成立することに対する信頼性を得る。

## 3. テストアイテム

- `calculateNetMonthly(salaryAnnual)` の社会保険料、課税所得、所得税、住民税、月手取り計算。
- `simulateRetirement(opts)` の月次シミュレーション、収入期間判定、生活費、投資利回り、ランダムイベント、投資補填、100歳12月までの出力。
- 給与変更設定の追加、削除、表示切替、有効入力抽出、優先順位、シミュレーションへの反映。
- 入力フォーム、開始操作、結果表示、注意表示、XSS対策、外部通信なし、データ永続化なし。
- 仕様で正式な回帰テスト資産とされた `sample_app/test_retirement_simulator.html` の存在、実行可能性、証跡、欠落時の扱い。
- コードベース自動テスト、Playwright E2E自動テスト、人間実行確認の成果物と実行証跡。

## 4. テストスコープ

対象範囲:

- 仕様書 v1.3 を正とした計算ロジック、境界値、異常値、丸め、表示フォーマット。
- 現役、退職後、年金受給の期間遷移と、`pensionStartAge <= retirementAge` など年齢前後関係が逆転した入力。
- 投資積立、年初利息、現金不足時の投資補填、投資不足時のマイナス資産継続。
- ランダムイベントは、発生率0%または100%、必要に応じた乱数差し替えで判定可能な範囲。
- 給与変更は、開始年齢前、開始年齢同年、退職年齢以降、同一年齢複数設定、無効設定を含む。
- Playwright代表環境の Chromium、Firefox、WebKit での主要操作、表示、安全性、互換性確認。
- 正式回帰テスト資産は、存在確認、ブラウザ実行可能性、実行証跡取得、欠落時の可視化を対象に含める。
- 基本的なキーボード操作、ラベルの意味推測、読み取りやすさ。

対象外または制約:

- 実税制、年金制度、投資税制、NISA等の実制度との差分は仕様上の制約であり不具合扱いしない。
- JavaScript無効環境は対象外。残リスクとして、JavaScript無効利用者には本アプリを提供できないことを制約事項として扱う。
- 800×600未満の正式保証は対象外。代替確認として、人間実行確認でベストエフォート表示を観察し、結果を残す。
- Safari実機固有差異の完全検証は対象外または人間実行確認範囲とする。Playwright WebKitで代表確認し、実機確認範囲は未決事項に残す。
- 人間実行テストは本プロセスでは実行せず、未実行として最終レポートに残す。
- 依存関係やPlaywrightブラウザが不足する場合は、ユーザー承認なしにインストールせず、N/Aまたはインフラ課題として記録する。

## 5. テスト終了条件

- テスト計画、分析、設計、ケース、テストコード、E2Eテストのレビューで、修正すべき `P0` / `P1` 指摘が残っていない。
- 実装可能なコードベース自動テストとE2E自動テストが作成され、`package.json` の該当コマンドまたは記録用スクリプトで実行結果が保存されている。
- 正式回帰テスト資産の存在確認、実行可能性、証跡、または欠落時の扱いが成果物に記録されている。
- Fail、N/A、未実装、未実行、人間実行待ち、質問待ち、正式テスト資産欠落が最終HTMLレポートまたは発見issue一覧で可視化されている。
- 仕様書で確定済みの期待値、丸め、許容差、性能閾値、互換性条件を、成果物上で `要確認` のまま残していない。
- 重大な計算誤り、外部通信、HTMLとしてのユーザー入力解釈など、ユーザー影響が大きい既知問題は発見issue一覧に記録されている。
- 未決事項は `## 10. 未決事項` に集約し、正式なリリース可否判断者、承認プロセス、Safari実機確認範囲など、プロダクト判断が必要なものを本文中に散らしたままにしない。
