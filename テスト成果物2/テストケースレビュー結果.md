## 4. レビュー・修正サマリー

### 第1回レビュー

| 優先度 | 観点 | 問題 | 場所 | 影響 | 修正方針 |
|---|---|---|---|---|---|
| P0 | 全体 | なし | - | - | - |
| P1 | 全体 | なし | - | - | - |
| P2 | 質問管理 | `TC-E2E-008` は実行可能だが、実機Safari要否の質問 `QD-004` にも関連している | `テストケース_E2E自動.md`, `テストケース_質問待ち.md` | 最終レポートでWebKit代表確認と実機Safari未確定を分けて説明する必要がある | E2Eは実行し、実機Safariは残課題として扱う |
| P2 | 実装容易性 | 一部コードベースケースは実装時に共通ヘルパーで期待値算出が必要 | `TC-CB-001` から `TC-CB-027` | 実装が冗長になる可能性 | テスト実装時に仕様式ヘルパーと出力解析ヘルパーを用意する |
| P3 | 人間実行 | 人間実行ケースの実施者未確定 | `テストケース_人間実行.md`, `テストケース_質問待ち.md` | 今回の自動ワークフローでは未実行として残る | 最終レポートに未実行として表示する |

修正対象となるP0/P1 findingsはなかったため、テストケースファイルおよび上流成果物の変更は行っていない。

## 5. 最終レビュー結果

4つのテストケースファイルは、必須構造とテーブルを持ち、`TD001` から `TD042` を全体でカバーしている。質問待ちケースは `テスト成果物/テストケース_質問待ち.md` に分離され、関連質問IDを持っている。

最終レビュー時点で、修正必須の `P0` および `P1` findings は残っていない。

## 6. 残課題

| 優先度 | 残課題 | 推奨対応 |
|---|---|---|
| P2 | 実機Safari確認の要否が未確定 | Playwright WebKitは実行し、実機Safariは質問票と最終レポートに残す |
| P2 | コードベーステスト実装で期待値ヘルパーが必要 | `calculateExpectedNetMonthly` と出力解析ヘルパーをテストコード内に実装する |
| P3 | 人間実行テストの担当者未確定 | 今回は未実行として扱い、後続で担当者決定後に実施する |
